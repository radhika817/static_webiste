# TechNova — College Event Website

A modern, responsive static website for a college technology festival.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive navigation
- Event cards
- Event schedule
- Contact section
- Mobile-friendly layout

## Run Locally
Open `index.html` in your web browser.

## Live Demo
Visit the project website here: [TechNova Website](https://radhika817.github.io/static_webiste/)

Built to learn the fundamentals of HTML, CSS, JavaScript, and Git.
