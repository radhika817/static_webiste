# TechNova — College Event Website

A modern, responsive static website for a college technology festival.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive navigation
- Event cards
- Event schedule
- Contact section
- Mobile-friendly layout

## Run Locally
Open `index.html` in your web browser.

## Learning Goal
Built to learn the fundamentals of HTML, CSS, JavaScript, and Git.
